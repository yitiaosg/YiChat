# YCards：实体参数、效果遮罩与生产优惠（2026-10-10）

入口仍为 `/ycards/`；管理员入口仍为 `/admin-panel/`。此次改动继续使用原用户、point 账户、积分流水、数据库和网站服务。

## 实体与渲染

卡片厚度固定 0.76 mm，圆角半径固定 3.18 mm（直角卡半径为 0）。设计 v2 保存 `thickness_mm`、`corner_radius_mm`。塑料侧面为黑色，玻璃侧面为半透明透光色；侧面根据实际厚度与旋转投影，侧转 90° 后仍可见。塑料保留黑底，不允许翻背；玻璃保留正反面。整体旋转与 ±45° 图层视差限制不变。

修正卡前／卡后的视差偏移符号：正深度在 rotateY 正向时向右、rotateX 正向时向上偏移。空间遮挡仍由深度和同深度图层顺序决定。旧正式文件不重写；旧成品圆角在渲染时适配 3.18 mm，新生产直接保存新的实际轮廓。

## 两种遮罩与计费

图片层仍只接收 PNG，保留原半透明。其他四类效果均可使用以下两种遮罩，可单独启用或同时取交集：

1. `mask`：原 PNG／SVG 范围遮罩；上传后自动使用 `scope=custom`。
2. `repeat_mask`：多行英文文字或 PNG／SVG 图案。支持无衬线／衬线／等宽字体、字体或图案高度、图案宽度、横向间距、行密度、倾斜角度及 X／Y 偏移。

两类遮罩都遵守二值作用区域：原 alpha=0 不生效，其余完全生效。外部 SVG 资源、脚本和路径穿越继续拒绝。客户端导入、调整、遮罩处理只发生在本地；只有存草稿或保存才上传。正反面每类 64 层上限保持不变。

| 效果 | 无遮罩基础费用 | 每种遮罩 |
|---|---|---|
| 流光（彩色／黑白） | +300 point；卡前额外 +100 | +200 point |
| 光晕 | +200 point；卡前额外 +50 | +200 point |
| 负片／光栅滤镜 | ×1.5 | ×1.25 |
| 镀金／镀银 | ×1.5 | ×1.25 |
| 黑胶 | ×2 | ×1.25 |

仍为整卡一次 100 point 基础费。先合计所有加价，再叠乘所有倍率，最后统一向上取整；两种遮罩均启用时，滤镜／材质增加 `1.25 × 1.25`。客户端使用 BigInt、服务端使用整数有理数进行同规则计算。

流光现在是完整范围的彩色／黑白反射效果，文字不再是流光效果本身，而是独立多行遮罩。黑白流光使用中性灰度，两者同价。工厂生产的多行遮罩以整张 4×4 版面为连续坐标：裁取相邻格时可能得到不同图案位置，漏裁连接和裁歪仍按实际成品 bounds 裁取。个人生产以单卡为坐标。原有漏印和歪印继续作用于该版整个图层。

## 新效果

- 原 `circle` 光晕改为 `ring` 环形光晕，以图层设置的中心为圆心，随视角缩放半径。
- 所有光晕可调宽度 `glow_width`（mm）、羽化 `feather`（0～1）、不透明度 `opacity`（0～1）和颜色 `tint`（六位十六进制）。这些参数不加价。
- 新滤镜 `lenticular`（光栅），倍率 ×1.5。对已渲染内容施加竖向柱面条纹的局部折射、轻微模糊和明暗反光，可调间距 `pitch_mm` 与强度 `strength`。这是浏览器中的视觉模拟。
- 镀金、镀银和黑胶在遮罩边缘增加随视角变化的亮边／暗边，使材质呈现薄层浮起的感觉；不改变生产费用。

旧版正式模板保持设计文件与原始成本不可变；渲染兼容旧 `foil.text/pattern`、`glow.circle`。打开旧草稿或创建编辑副本时转换为 v2，再保存按新规则计算。不会修改原模板、已有实例或历史生产费用。

## 优惠码

生产对话框新增“优惠码”输入框。输入后点击计算报价，查看原价、减免、实付和原生产时间，再提交生产。每批次最多一个优惠码。

- `test`：仅当前 role=admin 可以使用；免除此次整个批次费用，包含改善投入。没有永久免费开关，下一次须重新输入。原生产时长、损耗概率、成熟度、生产编号规则不变。
- 支付比例：管理员填写 80 表示支付 80%（八折），支持到 0.01%，0 表示免费；整 point 向上取整。
- 固定减免：减免指定整数 point，实付最低为 0。
- 优惠作用于生产费加改善投入的总额；不叠加优惠码，不缩短生产时间。
- 可配置截止时间、总使用次数和每人次数，次数 0 表示不限。优惠码区分大小写；任何大小写的 test 都不能作为普通优惠码创建，内置测试码仅为小写 test。

新增 `yc_coupons` 与 `yc_coupon_uses`，仍在 `userdata.db` 中。报价后若优惠码停用、过期、版本变化或次数耗尽，生产被拒绝并要求重新报价。核销与积分扣款、任务创建、编号分配同处 `BEGIN IMMEDIATE` 事务；不足余额不消耗优惠次数，最后一次优惠并发提交只有一次成功，幂等重试不重复扣款或核销。

## 管理员看板

完成原管理员身份验证后，打开“YCards · 优惠码”：

- 点击任一数据表计数进入 SQLite 阅读器。
- 正式模板、草稿、成熟度、序列、批次、逐版生产、损耗、仓库、挂售、交易、拍卖、报价及优惠数据均增加中文表名、字段名和状态显示。
- 用户筛选支持当前所有者、生产者、卖家、买家、获胜者及创建者；逐版任务和损耗记录通过关联查询筛选用户。
- point／分单位明确区分；JSON 格式化显示，内嵌图片显示资源标记。
- 选择支付比例或固定减免，填写限制后“一键创建优惠码”。码留空时自动生成。可启用／停用已有码，展示使用次数。
- 接口沿用原 admin 角色实时校验、管理员验证授权、CSRF 和审计。普通账户无法创建优惠码或查看管理数据。

## 文件

`ycards.py`：v2 校验、精确计费、实际圆角、生产优惠接入、admin 识别与任务优惠记录。

`ycards_promotions.py`：优惠表、规则校验、折扣报价、核销记录、创建／启停／查询。

`static/ycards-render.js`：厚度、方向修正、双遮罩、整版坐标、环形光晕、光栅和材质边缘。

`static/ycards.js`、`static/ycards.css`：图层编辑参数、客户端计费、生产优惠输入与展示。

`admin_panel.py`、`templates/admin_panel.html`：YCards 数据适配与优惠管理。

`tests/test_ycards_v2.py`、`tests/ycards_v2_fixture.py`、`tests/ycards_v2_check.mjs`、`tests/run_ycards_v2_checks.sh`：临时数据库及浏览器验证。原裁切测试同步调整半径断言。
