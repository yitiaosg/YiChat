# YCards 玻璃、滤镜、裁切与主页展示修正

## 行为与使用

- 玻璃图片图层正反相通。翻转时，原卡前图片成为远侧图片，原卡后图片成为近侧图片，遮挡顺序随朝向改变。背面设计使用其本地坐标，透视图片具有物理镜像关系。
- 卡面效果双面可见；卡前效果只在该面朝向观察者时可见，包括距离为 0 的卡前效果。玻璃两面图层仍共同受各类型 64 层上限约束。
- 滤镜处理在它下方已经合成的图片、材质、流光和光晕。负片保留玻璃透明度，并反转透过它的实际网页背景。光栅对透过玻璃的背景增加相应局部模糊。负片与光栅交替叠放时，背景处理顺序与图层顺序一致。
- 编辑器列表顶部现在表示同空间深度的最上层；上移箭头提高叠放顺序。空间深度仍优先，卡面滤镜不会覆盖实际位于其前方的图层。已有设计的保存顺序和成本不改动。
- 公开主页只显示实际卡片，去掉卡片展示标题、名称、边框、底板和空框占位。小屏每行 3 张、大屏每行 6 张；点击不导航。编辑主页继续提供展示框管理控件。

## 裁切约定

4×4 整版横三刀、竖三刀，每刀贯穿整版。单刀漏裁会产生四组两张连体卡；多刀漏裁可产生更大连体成品。全部格子仍且仅属于一个实际成品，展示 CID 取该成品的最小格子号。

圆角版有 25 个网格节点。有效横竖刀移除经过节点的圆角边角料；没有有效刀经过的角料保留。连体接缝在整版两端保留角料，经过另一有效裁线的地方呈现去除边角料后的凹口。

另四刀仅作用于整版四角：左上 `(0,0)`、右上 `(4,0)`、左下 `(0,4)`、右下 `(4,4)`，分别为格子 1、4、13、16 的对应外角。因此一刀圆角漏裁只产生一个直角。圆角裁歪只影响该外角；漏裁与裁歪并发仍同时记录，但漏裁不执行该次偏移。

新生产几何标记 `cut_model=2` 并保存每个覆盖格的角料扇区。客户端以损耗记录和实际裁线计算轮廓与侧面，旧卡自动采用修正规则。不重抽损耗，不改已有实例 ID、CID、归属、积分或交易记录，不重写正式模板和损耗文件。

## 修改文件

- `ycards.py`：整版四角操作与网格边角料归属。
- `static/ycards-render.js`：玻璃穿透、实际深度排序、滤镜背景合成、裁切轮廓及相应厚度侧面。
- `static/ycards.js`：编辑器图层列表方向及说明。
- `static/ycards-showcase.js`、`static/ycards-showcase.css`、`templates/ycards_showcase.html`：公开主页只显示卡片。
- `YCARDS.md`：更新裁切与玻璃规则。
- `tests/test_ycards_cuts.py`：新增裁切回归；两个已有测试文件同步更正旧圆角预期。
- `tests/ycards_optics_check.mjs`、`tests/run_ycards_optics_checks.sh`：新增真实浏览器光学检查与网页背景像素验证。
- `tests/ycards_render_check.mjs`、`tests/ycards_collection_check.mjs`：更新规则描述及公开展示检查。

```sh
YCARDS_CHROME=/path/to/chromium bash tests/run_ycards_optics_checks.sh
YCARDS_CHROME=/path/to/chromium bash tests/run_ycards_collection_checks.sh
```

76 项服务端测试通过，包含全部 64 种横竖漏裁组合、四角独立漏裁/裁歪、边角料归属和全部格子无重复分配。浏览器光学检查、原渲染/编辑器/优惠回归、仓库与主页管理回归通过。检查截图实际网页背景反转像素，验证材质和图片负片、双负片抵消、玻璃前后遮挡、远侧效果隐藏、连体凹口、旧卡轮廓、公开主页无文字边框、390px 三列与1440px 六列、点击无跳转。所有测试使用临时数据库。

负片背景使用浏览器混合合成，光栅使用 Canvas 模糊/条纹和 CSS backdrop-filter 模拟；不采集或上传网页背景。真实移动设备和不同浏览器的观感、性能未逐机验证。此次请求没有留待确认的功能项。
