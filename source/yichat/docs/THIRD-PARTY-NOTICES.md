# Web dependencies

The lockfile records the exact dependency graph. Runtime packages include:

- Preact — MIT — https://github.com/preactjs/preact
- matrix-js-sdk — Apache-2.0 — https://github.com/matrix-org/matrix-js-sdk
- matrix-sdk-crypto-wasm — Apache-2.0 — https://github.com/matrix-org/matrix-rust-sdk-wasm
- matrix-encrypt-attachment — Apache-2.0 — https://github.com/matrix-org/matrix-encrypt-attachment
- Lucide — ISC — https://github.com/lucide-icons/lucide

Build/test tools include Vite (MIT), TypeScript (Apache-2.0), tsx (MIT), and the existing Playwright browser fixture. Dependencies retain their original LICENSE files in npm distributions. The original project YCard renderer, game SVGs and extracted game layout remain project assets, with their existing provenance.
