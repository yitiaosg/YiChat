## 本轮追加验证

遵照用户最新要求，只在浏览器验证新增行为，未继续 Android 模拟器运行或扩大后端测试。最终签名 Release 构建通过，10 个嵌入框架文件与最终生产网页逐字节一致。

新增实际浏览器检查包含群主设置/移除头像、接收方刷新显示、转让后旧群主与非群主原生写入均403；移除 SAS 设备验证但原生密钥备份仍可用；内部原包 SHA 核验、连续最多5日限制、缺包/篡改拒绝；真实已封存 ZIP 本地读取及修改后服务器返回 mismatch；新设备输入恢复密钥后恢复私聊；主站账户页退出另一设备，该关联 Chat 页面收到失效并调用 App lock。检查所有核验 HTTP 请求只含日期/摘要/元数据，恢复密钥未出现在请求正文中。普通实时消息没有标为已核验。

测试中的原生 App 端口由 Playwright 替代，内部原包摘要使用真实隔离服务器返回的接受密文，在浏览器重新计算并对真实服务端摘要比对；Kotlin 桥接及本地原包读取代码通过 Release 编译。没有把浏览器端口替代视为 Android 原生运行通过。归档使用隔离时钟封存，不影响线上日期或数据。

本轮未进行 Android 真机验收，系统安全区、实际系统浏览器授权返回、文件选择、后台备份与 Kotlin 原包读取由用户安装后验证。前期云模拟器环境未完成原生运行验收，不计为通过。
